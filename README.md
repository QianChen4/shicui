# 拾萃 · 高中生物好题本

拾萃是一个给高中生物老师用的题库和组卷工具：录题、打 tag、记下学生常错的地方、找题、组卷导出 Word / PDF。
整个程序只有一个文件 `拾萃.html`，用 Mac 上的 Google Chrome 打开就能用，不用安装，题目都存在你自己电脑上的数据文件夹里。

## 第一次使用

1. **下载程序**：在本页上方点开 `拾萃.html`，点右上角的下载按钮（Download raw file）保存到电脑。
2. **放到固定位置**：比如放进“文稿”里新建的“拾萃”文件夹。以后在线更新会直接替换这个文件，所以不要放在“下载”里随手删掉。
3. **用 Chrome 打开**：在 `拾萃.html` 上点右键 →“打开方式”→“Google Chrome”。Mac 默认会用 Safari 打开，而 Safari 用不了拾萃。想以后双击就用 Chrome 打开，可以右键 →“显示简介”→“打开方式”选 Chrome，再点“全部更改”。
4. **选数据文件夹**：第一次打开时，拾萃会请你选一个文件夹存放题库（可以新建一个空文件夹，比如“拾萃数据”）。Chrome 问是否允许修改时，点“允许”。以后打开会自动用这个文件夹，有时需要再点一次“允许”。

## 日常怎么用

- **工作台**：打开后的首页，按用途分成“录题与数据”（录入新题、批量导入、备份、回收站）、“知识整理”（知识笔记、考点关系图）、“课堂与回顾”（课堂抽题、学期回顾）几组，还有待处理、每日一题、我的题集和录题日历。点右上角“工作台”或左上角“拾萃”随时回来。
- **录题**：按人教版（2019）教材的章节录入，支持选择题、判断题、填空题、简答题等，可以贴图片，并调整每张图的大小。工具栏里的“公式”可以插入化学式和反应式（箭头上下能写反应条件，常用的有现成模板），打印和导出 Word 时都能正常显示。
- **记下做错的地方**：录题时可以标出学生（或自己）曾经误选的选项、判错的判断、答错的空，之后能用“曾做错”筛出来。
- **打 tag、找题**：给题目打考点和题型 tag；左侧可以切换“全部 / 高一 / 高二 / 高三”；顶部搜索框边输边出结果，直接输数字按题目编号查找。常用的筛选可以“存为题集”。
- **批量导入**：把整理好的导入文件（可以让 AI 从 Word 或截图整理）在工作台“批量导入”里选中，先预览每道题，勾掉不要的、看看标出的可能重复题，确认后才写进题库；导错了可以在导入完成时或“设置 → 导入”里撤销最近一次导入。
- **组卷和导出**：勾选“选入试题篮”，在试题篮里拖动排序、设分值，导出 Word，或打印 / 存为 PDF（学生卷、教师用卷、卷尾附答案）。组好的卷保存在顶栏的“我的组卷”里，以后再打开。
- **试卷库**：导入并查看整套试卷（外校卷、高考卷、模拟卷），需要的题再“收进题库”。
- **考点关系图**：工作台里打开，看哪些考点常一起考。鼠标停在圆点或连线上会出现一行小提示，点一下右边列出详细情况，滚轮缩放、拖动平移。
- **其他**：知识笔记、学期回顾、课堂抽题、回收站（删除的题保留 30 天）、深色模式（设置里切换）。

想先看看效果，可以在地址栏的文件地址后面加上 `?demo` 打开演示数据，不会动你的题库。

## 数据和备份

- 题目、tag、试题篮和设置都在数据文件夹的 `bank.json` 里，图片在 `images/`，请不要手动修改。
- 每天第一次打开时会自动备份到 `backups/`，保留最近 14 天。
- 换电脑或另外备份：把整个数据文件夹复制过去，在拾萃里选中它即可。

## 更新

拾萃打开后会自动检查新版本，有新版时在角落提示；也可以在“设置 → 程序更新”里点“检查更新”。
更新会先备份旧版程序到数据文件夹的 `backups/`，再替换你正在用的 `拾萃.html`，题目数据不受影响。
第一次更新时需要在弹出的窗口里选中正在用的 `拾萃.html`，之后就不用再选了。连不上 GitHub 时会自动改用国内加速地址。

**从旧地址搬过来的用户**：v2.11.1 及以前的拾萃还在找原来的 GitHub 地址，那个地址已经不能用了，所以收不到更新提示。请按上面第 1、2 步从本仓库下载新的 `拾萃.html`，替换掉你电脑上原来那个文件（数据文件夹不用动），之后就能照常在线更新了。

各版本改了什么，见 [更新记录.md](更新记录.md)。
